# E-Commerce-Sales-dashboard using POWER BI 

This was my first Power BI dashboard, created by following a YouTube tutorial as part of my learning process.

In this project, I analyzed an e-commerce sales dataset using Power BI. The dashboard includes key performance indicators (KPIs), interactive slicers, and various visualizations to analyze sales, profit, customer behavior, payment modes, product categories, and regional performance. This project helped me understand how to transform data, create data models, build DAX measures, and design interactive dashboards that provide meaningful business insights.

Key Learnings:
Data cleaning and transformation using Power Query
Creating data models and establishing relationships
Writing basic DAX measures and calculated fields
Building interactive dashboards using slicers and visuals
Designing KPI cards and business reports
Presenting data in a clear and visually appealing format

Tools Used: Power BI, Power Query, DAX
